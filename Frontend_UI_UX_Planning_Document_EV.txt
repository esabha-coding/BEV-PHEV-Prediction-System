BEV/PHEV Vehicle Classification Dashboard
Business/analytics dashboard layout for automotive &amp; energy stakeholders
KPI cards: total vehicles, BEV count, PHEV count, average electric range, average base MSRP
Vehicle search and lookup (by VIN, Make, Model, or County)
Prediction panel: input vehicle specs and get a live BEV vs PHEV classification with confidence score
Category cards (e.g. Long-Range BEV, Entry PHEV, Premium BEV, Legacy Low-Range)
Feature importance chart (which specs drive the Random Forest / Decision Tree prediction)
Confusion matrix heatmap and ROC curve for model evaluation
Pie chart: BEV vs PHEV distribution across the population
Bar chart: top manufacturers by registration volume
Interactive map: geographic distribution of EVs by Washington County / Legislative District
Filters: County, Make, Model Year range, CAFV eligibility, electric range range
Export option (CSV / PDF report of predictions and filtered results)
Responsive design across mobile, tablet, desktop
Loading animation during classification/model calls
Toast notifications for actions (export success, filter applied, errors)

Final Goal
The frontend should look like a commercial automotive-analytics product rather than a university assignment. It should provide an intuitive experience, premium BMW-inspired branding, an interactive geographic map, clear model-explainability visuals, and seamless integration with a backend serving the Random Forest / Decision Tree BEV-PHEV classification model.
