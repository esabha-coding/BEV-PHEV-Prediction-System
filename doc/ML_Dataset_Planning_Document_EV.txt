Machine Learning Dataset Planning Document
This document defines the selected dataset for the BEV/PHEV Vehicle Type Prediction project, including the official data source, feature engineering plan, and classification approach.
Project: BEV vs PHEV Prediction (Supervised Classification)
Dataset
Washington State Electric Vehicle Population Data (Washington State Dept. of Licensing)
Industry
Automotive / Transportation &amp; Energy Analytics
Reason
Large-scale, real-world government registration dataset covering the full population of licensed EVs in Washington State; well suited for predicting vehicle drivetrain type from specification and registration attributes.
Records
135,038 vehicle records, 17 columns
Official Source
https://catalog.data.gov/dataset/electric-vehicle-population-data (Washington State Dept. of Licensing, via data.wa.gov)
File Format
CSV
Primary Algorithms
Random Forest Classifier, Decision Tree Classifier
Target Variable
Electric Vehicle Type — Battery Electric Vehicle (BEV) vs Plug-in Hybrid Electric Vehicle (PHEV)
Class Balance
BEV: 103,882 records (~76.9%) | PHEV: 31,156 records (~23.1%) — moderate class imbalance (~3.3:1)
Feature Engineering
Make, Model Year, Electric Range, Base MSRP, CAFV Eligibility, County, Legislative District used as predictive features; Model and Electric Utility encoded as high-cardinality categoricals; VIN and DOL Vehicle ID excluded as identifiers
Preprocessing Notes
Drop VIN (1-10) and DOL Vehicle ID (identifiers, not features); impute or drop rows with missing County/City/Postal Code/Model/Electric Range/Base MSRP/Legislative District; label/one-hot encode Make, CAFV Eligibility, and County; address class imbalance via class-weighting or resampling; StandardScaler on numeric features (Electric Range, Base MSRP, Model Year)
Expected Output
Trained BEV/PHEV classifier evaluated via accuracy, precision, recall, F1-score, and confusion matrix; feature importance ranking to explain which specifications most strongly predict drivetrain type
